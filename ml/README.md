Classification of plant glycoside hydrolases from amino acid sequences using protein language model embeddings

Применение сверточных нейросетей (CNN) и трансформеров для классификации ферментов класса гликозил-гидролаз по их первичной структуре

Исследование применимости embeddings белковой языковой модели ESM-2 для классификации функционально различных гликозид-гидролаз семейства GH13 растительного происхождения.
###
Investigating ESM-2 protein language model embeddings for functional classification of plant glycoside hydrolases from CAZy family GH13.
