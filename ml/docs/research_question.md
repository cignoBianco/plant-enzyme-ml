# Research Question

## Working title

Classification of plant glycoside hydrolases from amino acid sequences using protein language model embeddings.

## Research question

Can amino acid sequence representations obtained from a protein language model
be used to distinguish functionally different glycoside hydrolases?

## Main hypothesis

Protein language model embeddings contain information related to the functional
properties of glycoside hydrolases and can be used as features for enzyme classification.

## Object

Plant glycoside hydrolases.

## Input

Amino acid sequences of proteins.

## Target

Enzyme functional class / activity.

## Main model

ESM-2.

## Downstream classifiers

Logistic Regression, Random Forest, XGBoost.

## Main data sources

CAZy and UniProt.
